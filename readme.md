# WithFit（ウィズフィット）🏋️‍♂️🔥

> **「みんなで鍛える、記録アプリ」**  
> 友人同士でトレーニング記録・重量・体組成データを共有し、モチベーションを高め合える高機能ソーシャルワークアウトトラッカー（PWA / Webアプリ）。

---

## 📌 概要

**WithFit** は、本格的なウエイトトレーニング（BIG3強化、クラシックフィジーク、ボディビル、パワーリフティング）に取り組む仲間たちに向けたクローズドなトレーニング共有プラットフォームです。

ジムごとのマシン・フリーウェイト管理、スーパーセットやドロップセット、補助回数（Forced Reps）、自重の荷重／アシスト切り替え、リアルタイム合トレ同期、科学的ピリオダイゼーション（HPS・Smolov Jr.・5/3/1）の自動計算など、ハードトレーニーが必要とする機能を徹底的に追求しています。

## ✨ 主要機能一覧

### 1. ワークアウト記録（Record）
- **トレーニング場所の柔軟な管理**
  - 所属ジム（エニタイム、ゴールドジム、地域ジム等）とフリーウェイト（共通）の切り替え。
  - **記録画面からトレーニング中のジムをいつでも変更可能**。
- **多彩な負荷タイプに対応**
  - 合計重量（kg）
  - 片側重量（kg）
  - プレートロード（枚）
  - 左右別（L/R別レップ数・重量）
  - **自重種目（＋荷重／－アシスト切替ボタンをワンタップで選択可能、iOS数字キーボード直結）**
  - 有酸素運動（距離・時間・消費カロリー）
- **高度なセット構成**
  - 通常セット
  - ドロップセット（多段階ドロップに対応）
  - スーパーセット / ジャイアントセット（2種目目・3種目目の同時記録）
  - 補助回数（Forced Reps）
- **過去の投稿からの「構成コピー」**
  - 過去の自分の投稿やフレンドの投稿から、種目構成をワンタップで現在のジムの記録画面に追加。
  - 開始前は記録画面上の「トレーニング開始」ボタンを押すことで、3分後のフレンド自動通知タイマーが正しく起動。
- **リアルタイム合トレ（Joint Training）**
  - 同じジムにいるフレンドを自動検知して合トレ申請。
  - 2人の記録カードがリアルタイム同期され、完了時に2人分の投稿を自動生成。
- **フローティング・インターバルタイマー**
  - ワークアウト経過時間タイマー ＋ 休憩タイマー（UP / 1〜5分、音・バイブ通知）。
  - スマホ画面の端にスワイプで退避できるフローティングUI。
- **開始3分後通知 & 記録忘れリマインダー**
  - トレーニング開始から3分後にフレンド全員へ「🔥 トレーニング開始！」通知を自動配信。
  - 30分間操作がない場合の記録忘れ防止通知。

### 2. 体組成記録 & 分析（Body Metrics）
- **体重・体脂肪率の記録**
  - ワークアウトと同時の記録、または「体組成のみ記録」に対応。
  - 体組成のみの投稿でも、後から編集・保存が可能。
- **指標の自動算出**
  - 除脂肪体重（LBM）、FFMI（除脂肪量指数）、基礎代謝量（BMR）を自動計算。
- **プライバシー保護**
  - 体組成データはプロフィール設定からフレンドに対して「非公開（ないしょ♡）」に設定可能。

### 3. タイムライン & ソーシャル（Timeline & Friends）
- **フィード投稿**
  - 実施種目、セット詳細、推定1RM、自己ベスト更新（🏆重量PR / 🎖️レップPR）バッジ。
  - 総負荷量メタファー（例:「サイ約2.5頭分」「アフリカゾウ級」）。
- **コミュニケーション**
  - ナイス（いいね）機能、ナイスしたユーザー一覧モーダル。
  - コメント機能（`@ユーザー名` によるメンション通知、スレッド返信）。
- **リアルタイム通知センター**
  - ナイス、コメント、合トレ申請、フレンド申請、トレーニング開始通知を即座に受信。
  - Web Push（Service Worker / FCM）によるバックグラウンドOS通知対応。

### 4. プログラム自動作成 & 管理（Program Management）
- **科学的プログラムジェネレーター**
  - **HPSトレーニング**: 6週間（筋肥大・瞬発力・最大筋力の非線形ピリオダイゼーション）。
  - **Smolov Jr.**: 3週間（高頻度・高ボリュームの集中ピーキング）。
  - **5/3/1 プログラム**: 4週間（1RMの90%を基準とした長期筋力向上・AMRAP）。
- **本日のメニューへワンタップ反映**
  - 1RMを入力するだけで目標重量・レップ数・セット数を自動計算し、今日のワークアウトへ直接追加。

### 5. 種目 & ジム管理（Exercises & Gyms）
- **ジムグループ**
  - 新規ジムの作成、参加、退会（最後のメンバーが退会しても種目データは保持）。
- **種目リスト**
  - 部位別（胸・背中・肩・腕・脚・腹筋・有酸素・その他）カテゴリ。
  - 器具別（マシン・バーベル・ダンベル・スミス）フィルター。
  - 種目ごとの自己ベスト、総実施回数、最終実施日表示。
  - 種目成長率チャート & 推移グラフモーダル。
  - 使わない種目の非表示（ミュート）機能。
  - 押しやすい2×2配置のアクションボタン（推移グラフ・非表示・編集・削除）。

### 6. データ画面（Data & Reports）
- **カレンダービュー**: 過去のトレーニング履歴・体組成履歴の確認。
- **期間別グラフ**: 1か月 / 3か月 / 1年 / 全期間の推移チャート（タッチ時数値表示）。
- **月間レポート**: 総ボリューム、総セット数、トレーニング日数、部位別比率。
- **AIコーチチャット**: Gemini APIと連携したトレーニング相談機能。

## 🚀 デプロイ & コード更新フロー

WithFitは **GitHub（`main` ブランチ）へのプッシュを検知して、Vercelが自動的にビルド＆本番公開** を行います。

### 方法A: PCから更新する場合（`apdate.bat`）

1. AIから提供された `changes.json` を `src/changes.json` に配置します。
2. フォルダ内の **`apdate.bat`** をダブルクリックします。
3. `node src/apply_changes.js` が自動実行されてコードが置換され、Gitコミット＆プッシュが行われます。
4. 1〜2分後にVercelの自動デプロイが完了し、アプリへ反映されます。

> 💡 **リポジトリのフォルダ構成が崩れた場合**  
> `WithFit.zip` を解凍して中にある **`reset_github.bat`** をダブルクリックすると、GitHubの `main` ブランチを綺麗な状態に強制リセット（Force Push）できます。

---

### 方法B: スマホからPCなしで更新する場合（Mobile Deploy）

Vercelのビルド設定に `"build": "node src/apply_changes.js && CI=false react-scripts build"` が組み込まれているため、PCが手元になくてもスマホ単体でデプロイ可能です。

1. **GitHubスマホアプリ** またはスマホのブラウザで GitHubリポジトリ（`michitsuji/withfit`）を開きます。
2. `src/changes.json` を開き、編集ボタン（鉛筆マーク）をタップします。
3. AIから提示された `changes.json` の内容を貼り付けて、**「Commit changes」** を押します。
4. Vercelがビルド実行時にクラウド上で自動的に `apply_changes.js` を動かして各ファイルを置換し、約1〜2分で本番環境に自動デプロイされます。
